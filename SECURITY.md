# Security Policy

## Scope

This repository contains public documentation only. It does not contain the Agenova hosted agent, MCP server source, production broker, customer data, credentials, or deployment configuration.

## Reporting a vulnerability

Do not report security issues through public GitHub issues (Issues are disabled on this repository).

Use the private contact form: <https://agenova.ru/contact/>

Include:

- A concise description
- Reproduction steps or a proof of concept, without secrets
- Affected documentation or product area
- Potential impact
- A safe way to reach you

Do not include passwords, access tokens, customer data, or other secrets.

## Out of scope

- Feature requests
- Account or billing problems
- Copy edits to this documentation
- Vulnerabilities in Wildberries, Ozon, Bitrix24, or other third-party services
